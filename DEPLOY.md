# Как выпустить Powder Peak Tycoon

Игра — это один HTML-файл плюс папка `lib/` с 3D-движком. Сервер не нужен, поэтому её можно выложить почти куда угодно. Ниже варианты, от самого простого.

## 1. Сайт на GitHub Pages (бесплатно, 5 минут)

Это база для всех остальных вариантов: Telegram и PWA тоже открывают игру по ссылке.

1. В репозитории на GitHub: **Settings → Pages**.
2. *Source*: **Deploy from a branch**, ветка `main` (или эта ветка), папка `/ (root)`.
3. Через минуту игра откроется по адресу `https://etueque-blip.github.io/skis/`.

`index.html` — это сайт игры: описание, скриншоты и кнопка «Играть». Сама игра открывается из `powder-peak.html`. Если сайт открыт из Телеграма, он сразу запускает игру.

## 1б. Свой домен (например, powderpeak.ru)

Купить домен за тебя я не могу: это делается у регистратора на твоё имя. Примерная цена: `.ru` около 200–300 ₽ в год, `.com` и `.games` около $10–30 в год. Регистраторы: Reg.ru, Timeweb, Namecheap, Cloudflare. Сначала проверь, что имя свободно, например `powderpeak.ru`, `powder-peak.ru` или `powderpeak.games`.

1. Купи домен.
2. В репозитории на GitHub: **Settings → Pages → Custom domain** — впиши домен и нажми Save. GitHub сам создаст файл `CNAME`.
3. У регистратора в настройках DNS добавь записи:
   - для `www`: запись `CNAME` → `<логин>.github.io`
   - для корня домена: четыре записи `A` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
4. Через 10–60 минут включи в Pages галочку **Enforce HTTPS**.

После этого ссылку на домен можно дать и Telegram-боту.

## 2. Telegram Mini App (игра прямо внутри Телеграма)

В игре уже есть поддержка Telegram: когда её открывают из Телеграма, она разворачивается на весь экран, отключает сворачивание свайпом (чтобы можно было крутить камеру) и включает вибрацию при постройке.

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`. Придумай имя и юзернейм бота.
2. Отправь `/newapp`, выбери бота, задай название, описание и картинку 640×360.
3. Когда попросит ссылку (*Web App URL*), дай адрес с GitHub Pages из пункта 1.
4. Придумай короткое имя приложения. Получится ссылка вида `https://t.me/<бот>/<приложение>`. Её можно кидать друзьям и в каналы.
5. По желанию: `/setmenubutton` добавит кнопку «Играть» в чат с ботом.

Сохранения хранятся в памяти Телеграма на устройстве игрока.

## 3. Установка на телефон как приложение (PWA)

Уже работает после пункта 1:

- **Android (Chrome)**: меню ⋮ → «Установить приложение».
- **iPhone (Safari)**: «Поделиться» → «На экран „Домой“».

Игра получит свою иконку, откроется на весь экран и будет работать без интернета (файл `sw.js` кэширует её).

## 4. Яндекс Игры (большая русскоязычная аудитория)

Хорошо подходит для HTML5-игр, есть монетизация рекламой.

1. Зарегистрируйся в [консоли разработчика Яндекс Игр](https://yandex.ru/games/console/).
2. Загрузи ZIP-архив: `powder-peak.html` (переименуй в `index.html`), папку `lib/` и иконки.
3. Для прохождения модерации нужно подключить Yandex Games SDK (вызвать `LoadingAPI.ready()` после загрузки). Если решишь идти сюда, это можно добавить в игру.

Похожие площадки для браузерных игр: CrazyGames, Poki, itch.io.

## 5. Google Play и App Store

Игру можно обернуть в нативное приложение через [Capacitor](https://capacitorjs.com/):

```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init "Powder Peak" com.example.powderpeak --web-dir=www
# скопировать powder-peak.html (как index.html), lib/ и иконки в папку www/
npx cap add android && npx cap open android   # собрать в Android Studio
npx cap add ios && npx cap open ios           # собрать в Xcode (нужен Mac)
```

Что важно знать:

- **Google Play**: разовый взнос $25 за аккаунт разработчика.
- **App Store**: $99 в год, Mac с Xcode. Apple отклоняет «просто сайт в обёртке», поэтому лучше сначала добавить то, чего нет на сайте: офлайн уже есть, ещё помогут вибрация, Game Center (рекорды) и встроенные покупки.

## Почему не лагает

- Все лыжники рисуются за 5 вызовов отрисовки (инстансинг), а не по 4 на каждого. Кресла и кабинки так же: один вызов на подъёмник.
- Деревья и камни тоже инстансные.
- Четыре уровня графики (Низкая, Средняя, Высокая, Ультра) в меню ⚙ → «Графика». Игра сама выбирает подходящий для устройства и снижает его на ступень, если FPS падает ниже 26.
- 3D-движок лежит в `lib/`, поэтому грузится с того же сервера и работает офлайн.
