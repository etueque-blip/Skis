# Powder Peak

A 3D ski-resort builder that runs in the browser. Build chairlifts and gondolas, draw runs down a mountain, add hotels and restaurants, then ski your own runs yourself (skis or snowboard, slalom gates, tricks, ghost of your best run).

- Play: open `index.html` (the website) or `powder-peak.html` (the game).
- Works on phone and computer, installable as an app, works offline.
- Publishing guide (GitHub Pages, custom domain, Telegram Mini App, Yandex Games, app stores): [DEPLOY.md](DEPLOY.md).

Built with [three.js](https://threejs.org/) r128 (bundled in `lib/`).
